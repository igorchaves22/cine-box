# Overview

This project is a self-contained desktop application responsible for managing and playing a local media library. All business logic, processing, and data persistence occur locally on the user's machine, with no dependency on external services or cloud infrastructure.

> [!IMPORTANT]
> Project developed and tested exclusively for **Windows**. Support for other platforms is not guaranteed.

**Stack**

| Layer                  | Technology                       |
| ---------------------- | -------------------------------- |
| App foundation         | Electron                         |
| Primary language       | TypeScript                       |
| Database               | SQLite + Drizzle ORM             |
| Interface              | Vite + ReactJS + TailwindCSS     |
| Linting and formatting | EditorConfig + ESLint + Prettier |
